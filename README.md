# site-verification-and-workflow-management-system-176390-176401

This repository contains:
- flutter_frontend: Mobile app interface for site verification and workflow management.

Quick start for Flutter frontend:
1) cd flutter_frontend
2) flutter pub get
3) cp .env.example .env
4) flutter run

Ensure backend is running at BACKEND_BASE_URL (default http://localhost:3001). Preview for web typically opens around port 3000.
